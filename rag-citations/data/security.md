# NovaDesk Security

## Data protection

- Data at rest is encrypted with AES-256.
- Data in transit uses TLS 1.2+.
- Customer data is hosted in US-East and EU-West regions; customers choose residency at signup.

## Access control

- Role-based access control (Owner, Admin, Member, Guest).
- Optional SSO via SAML for Pro and Business plans.
- Audit logs retained for 90 days (Starter/Pro) or 365 days (Business).

## Compliance posture (fictional)

NovaDesk maintains SOC 2 Type II controls for the production environment.
EU customers can execute a DPA covering GDPR Article 28 processor obligations.
