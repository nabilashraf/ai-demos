# NovaDesk Overview

NovaDesk is a fictional cloud workspace suite for small teams. It bundles
shared documents, task boards, and a lightweight CRM into one subscription.

## Core modules

- **Docs** — real-time collaborative documents with version history
- **Boards** — kanban boards linked to Docs and CRM records
- **CRM Light** — contacts, deals, and simple pipelines

NovaDesk targets teams of 5–50 people who outgrew free tools but do not need
enterprise suites. The product ships as a web app with optional desktop sync.
